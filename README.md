# Insure Universe

AI-powered insurance business simulation. You are the CEO of a Thai non-life insurer competing against 4 AI companies.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
```

Status: Phase 1–2. CEO Command Center is playable as a visual prototype. Decision Room (Phase 3) and Quarterly Review + simulation (Phase 4) are next.

- Architecture → `docs/ARCHITECTURE.md`
- Art assets & what is still needed → `docs/ASSETS.md`
- All KPI numbers are mock values for the prototype.
